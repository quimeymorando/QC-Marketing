# Referencias de la web QC

Idea rectora: **cada página tiene su propia estética** para mostrar versatilidad. Cada referencia es un punto de partida que reinterpretamos con concepto, textos, gráficos y código propios. No copiamos textos, logos, modelos 3D, ilustraciones ni la idea central de nadie.

Lo que se mantiene igual en todas las páginas (para que siga pareciendo una sola marca):
- Logo QC, menú y botón de contacto: mismo lugar y comportamiento en todas.
- Transición entre páginas compartida (el "cambio de mundo").
- Footer común (contacto, redes, legales).

## Nota sobre la página About
Tomamos el **género** (JRPG de 8 bits: ventanas de menú azules con borde, sprites pixelados, selector con cursor, stats) pero no material de Final Fantasy: nada de su logo, nombre, personajes, sprites, música ni tipografías. Personajes, menú y sonidos se diseñan desde cero.
